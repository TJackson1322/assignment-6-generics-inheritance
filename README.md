# Assignment 6: Generics, Inheritance, and Method Overriding

This repository folder contains the Java example from the Assignment 6 paper. The program demonstrates inheritance, method overriding, and polymorphism using `Vehicle`, `SUV`, `sportsCar`, `Hybrid`, and `VehicleDemo`.

## Run the program

From this folder, compile and run:

```sh
javac VehicleDemo.java
java VehicleDemo
```

The output shows each vehicle's version of `forward()` and `reverse()`. These methods only print example messages; they do not control real vehicles.
